把一件事写进记忆。一个节点一件事，一件事一条笔记。

- 新的事：给 name 和 note。
- 同一件事改主意：给 event 加新的 note，那条整条换掉。
- 事情又长出另一面：另开一件，再用 link 连过去。
- 只改关系、不动内容：用 link。

name 是以后搜它的键：主语 + 动作 + 结果，6–24 字，单独读得懂。note 是记得的内容，一两段，写结论、数字、待办，不抄过程；它只在这几步的记录里，再往前就用 recollect 取。找旧事件用 recall 拿 id，改名用 rename，不要了用 forget。

## name
这件事的名字；和已有事件重名就是改那件。

## event
可选，要改的那件事（id 或唯一名字）。新开一件就别给。

## note
要记住的内容，一两段。改主意就整条重写。

## scope
long 长期，short 只留几天；默认 long。
