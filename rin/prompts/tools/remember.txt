把一件事写进记忆。一件事一条笔记。

**什么时候该记**（不是每步都记）：

- 对方说的事实、约定、偏好、在意的事（“我下周要考试”“我不喜欢被催”）；
- 你答应过什么、还没做完什么；
- 过一阵还会想起来的旧事；
- 你自己得出的判断、想留住的一个念头。
- 一次性的流水、翻回记录就能看到的东西，不值得记。

**新建之前会先按名字查一遍**：有一件名字很像的就不新建，会把候选给你——要并进那一件就把它的 id 放进 event，
确实是另一件事就换个更具体的名字再来。

- 新的事：给 name 和 note。
- 同一件事改主意：给 event 加新的 note，那条整条换掉。
- 事情又长出另一面：另开一件，再用 link 连过去。
- 只改关系、不动内容：用 link。

name 是以后搜它的键（**不是 id**）：主语 + 动作 + 结果，6–24 字，单独读得懂。note 写结论、数字、待办，不抄过程；
它只在这几步的记录里，再往前就用 recollect 取。找旧事件用 recall 拿 id，改名用 rename，不要了用 forget。

## name
必填。这件事的名字；和已有事件重名就是改那件。别把 e- 开头的 id 填在这里（那要填 event）。

## event
可选，要改的那件事（id 或唯一名字）。新开一件就别给。

## note
必填。要记住的内容，一两段；改主意就整条重写。

## scope
`long`（默认）：一直留着，以后 `recall` 得到。
`short`：过几天就只剩一句话的痕迹，`recall` 再也找不到——只在这阵子有用的东西（待办、临时安排）才用它。
