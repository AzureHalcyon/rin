在工作区里写一个文件（`<数据>/workspace` 下面，`run` 的当前目录也是那儿）。路径是相对工作区的，绝对路径和 `..` 会被拒；写之前自动建目录。

**与其他工具配合使用**：写进去的东西不进上下文，要看就用 run 的 `cat` / `ls` 读回来；写完的小脚本用 run 跑；想记住一个结论用 remember。

## path
相对工作区的路径，比如 `草稿/今天的想法.md`、`清单.txt`。

## content
要写的正文，原样写入（可以是空字符串，用来清空一个文件）。

## mode
可选：overwrite 覆盖（默认），append 追加到末尾。
